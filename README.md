# Createhattan Project

Cold war modpack for a certain voxel building game, forked from
[The Minehattan Project](https://github.com/LunarLoony/The-Minehattan-Project)
and updated for the Createhattan server. 95 mods, Minecraft 1.19.2, Forge 43.5.2.

Download the client pack from the
[Releases](https://github.com/GST-4649/Createhattan-Project/releases/tag/createhattan-1)
page, then import the .mrpack into your launcher of choice.

## What changed from upstream

- Create Crafts & Additions 1.2.3: Electric Motor (FE to rotation) and
  Alternator (rotation to FE at 75 percent).
- Sophisticated Storage replaces NABBA.
- Carry On, Tetra, Supplementaries, Relics, Artifacts, and more added.
- Pollution Of Create backport included as a local file.
- Peaceful Nights runs on the server only (no surface mob spawning).
- Forge updated to 43.5.2.

## Building

1. Get a copy of packwiz - https://packwiz.infra.link/
2. packwiz refresh
3. packwiz mr export

You can then import the .mrpack into your launcher of choice and play
Createhattan Project.

Note: this fork's changes were made with AI assistance.
